## 二、自我介绍（优势第一｜推荐主讲稿 · 约 90 秒）

**【招呼】**  
您好，我是吴贵良，应聘贵司的智能体训练师（AI Agent Trainer）／AI 应用方向。

**【优势第一 — 先立住差异】**  
我给自己的定位不是「只会调大模型聊天」，而是能把业务做成**可控、可测、可交接人工**的 AI 应用。核心优势有三条：

第一，**降幻觉的 RAG 客服能力**。在美匠化妆师平台里，我独立做过分层 RAG：章标题优先切分、查询改写、弱相关按分数拒答，并强制「知识库未命中先声明」，避免模型通识伪装成查库结论；同时用事实预取降低订单等交易字段幻觉。

第二，**Agent 工作流思维**。除了 Java / Spring AI，我还用 **Python + LangGraph** 做过签证客服智能体：意图分流、材料先槽位再检索、进度工具调用、投诉与高风险转人工、中风险用户确认，用 `flow_path` 把自主 / 确认 / 转人工写进节点，而不是靠模型自觉。

第三，**能独立交付的全栈工程习惯**。LIMS 实习里我能跑通需求澄清到联调上线，做过开放 API 幂等重试、文档引擎、多租户扩展；日常深度用 Cursor 做 AI 辅助开发，交付节奏快、排障也实战过（向量库 IPv6、网关 302 导致 POST 失败、Coze messages 格式问题等）。

**【经历一笔带过作证明】**  
教育上我是张家界学院计算机科学与技术 2026 届本科。实习在宏恩做 LIMS 全栈，在海晨做过审批流。个人项目美匠是 Spring Boot 3 + Spring AI Alibaba + DeepSeek 的智能客服；签证客服 Agent 是我对齐 Agent 训练师岗位补的 Python 编排闭环。

**【收束匹配岗位】**  
所以如果岗位要的是：会搭 Coze/工作流、懂知识库和工具调用、知道什么能自动答、什么必须确认或转人工，并且能用工程方式落地和迭代——这和我正在做的事是对齐的。我也可以按你们业务优先场景，先做客服或材料引导闭环。谢谢。

## 五、按「优势三条」展开的备用金句（被追问时用）

### 优势 1：RAG 不只检索，还做诚实与评测意识

美匠里我用 `rag-min-score` 区分命中/未命中双文案；切分上避免「只入库第一章」；客服侧 L1/L2/L3 记忆分层。目标是：**查库像查库，不知道就说不知道。**

### 优势 2：Agent 不是单 Prompt，是状态机

签证客服里：投诉走规则转人工；材料缺槽位先追问；进度先校验订单号再调插件；风控统一输出 ask/confirm/normal/handoff。目标是：**权限在流程里，不在模型心情里。**

### 优势 3：能把需求做成可上线功能

LIMS：开放 API 幂等重试、文档生成提效约 40%、SQL 与打印并发治理。说明我不是只会 Demo，能进业务系统协作交付。
