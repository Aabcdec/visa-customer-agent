# 签证风险评估政策

## 风险等级定义

### 低风险（low）
- 材料齐全、真实
- 有良好出入境记录
- 在职状态稳定（同一单位工作1年以上）
- 银行流水稳定，余额充足
- 行程合理，与签证类型匹配

### 中风险（medium）
- 部分材料存在瑕疵但不影响整体申请
- 出入境记录较少但无不良记录
- 自由职业者或新入职（工作不满6个月）
- 银行流水有波动但余额达标
- 行程安排有小范围不合理

### 高风险（high）
- 材料存在造假嫌疑
- 有拒签记录（尤其是近期拒签）
- 有非法滞留或遣返记录
- 无稳定收入来源
- 银行流水异常（大额突然存入）
- 行程与签证类型明显不匹配
- 敏感职业或背景
- 申请国与申请人背景关联性弱

## 常见拒签原因

### 材料问题
1. 提供虚假材料（永久记录，影响后续所有申请）
2. 材料不完整或缺失关键文件
3. 照片不符合规格
4. 翻译件未经认证
5. 在职证明与实际情况不符

### 资金问题
1. 银行流水余额不足
2. 近期大额存入，资金来源不明
3. 无稳定收入证明
4. 资产证明与收入水平不匹配

### 行程问题
1. 行程计划不合理（如7天游10个国家）
2. 无明确住宿安排
3. 行程与签证类型不符（持旅游签但无旅游行程）

### 个人背景
1. 有拒签史且未改善条件
2. 有非法滞留记录
3. 与目的国联系薄弱（无房产、无家庭纽带）
4. 敏感行业/职业背景

## 风险应对建议

### 低风险情况
- 正常准备材料，按流程递交
- 确保材料一致性
- 建议提前1-2个月申请

### 中风险情况
- 补充额外证明材料（房产证、车产证等）
- 提供更详细的行程计划
- 建议准备解释信说明特殊情况
- 提前2-3个月申请

### 高风险情况
- 建议咨询专业签证顾问
- 需补充充分的解释材料
- 拒签后建议间隔3-6个月再申请
- 考虑更换签证类型或申请国
- 建议提供更有力的约束力证明（国内资产、家庭关系等）

## 特殊情况处理

### 拒签后重新申请
- 分析拒签原因，针对性补充材料
- 建议间隔至少3个月
- 如条件无实质变化，不建议盲目重申
- 可考虑更换申请国（申根区内）

### 加急处理
- 部分国家支持加急服务（额外收费）
- 紧急情况（如商务紧急出行）可提供相关证明申请加急
- 加急不保证出签，仅加速审理流程

### 转人工服务触发条件
1. 用户涉及高风险情况且需要个性化建议
2. 用户有复杂拒签史需要专业分析
3. 用户涉及敏感国家或特殊签证类型
4. 用户对风险评估结果有异议需要人工复核
5. 用户需要紧急处理（3天内出行）
