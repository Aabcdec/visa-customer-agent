# 签证材料清单

## 通用基础材料（所有签证类型均需）
1. 有效护照（有效期需超过行程结束后6个月）
2. 近6个月白底彩色证件照（35mm×45mm）
3. 签证申请表（在线填写或纸质）
4. 身份证复印件
5. 户口本复印件（整本）

## 旅游签证材料清单

### 在职人员
1. 在职证明（公司抬头纸，含职位、薪资、入职时间、准假证明）
2. 公司营业执照副本复印件（加盖公章）
3. 近6个月银行流水（余额建议≥5万）
4. 行程计划表
5. 机票预订单（往返）
6. 酒店预订单
7. 旅行保险（申根国家强制要求）

### 自由职业者
1. 收入证明（近6个月流水）
2. 业务相关证明材料
3. 资产证明（房产、车产等）
4. 行程计划表
5. 机票预订单
6. 酒店预订单

### 退休人员
1. 退休证复印件
2. 退休金流水（近6个月）
3. 资产证明
4. 行程计划表
5. 机票预订单
6. 酒店预订单

### 学生
1. 学校在读证明
2. 学校准假证明
3. 学生证复印件
4. 父母在职证明和银行流水
5. 亲属关系公证件
6. 行程计划表

## 商务签证额外材料
1. 邀请函（对方公司出具）
2. 派遣函（中方公司出具）
3. 双方公司营业执照/注册证明
4. 商务往来证明（合同、邮件等）
5. 会议/展览注册证明

## 学生签证额外材料
1. 学校录取通知书（Offer/CAS/I-20等）
2. 学费缴纳证明
3. 资金证明（存款证明，通常要求存满28天以上）
4. 语言成绩单（雅思/托福等）
5. 学习计划（Study Plan）
6. 体检报告（部分国家要求）
7. 无犯罪记录证明（部分国家要求）

## 各国特殊材料要求

### 日本
- 担保人身元保证书（商务签）
- 学历证明（部分情况）
- 居住证（非户籍所在地申请时）

### 美国
- DS-160在线申请表确认页
- 面签预约确认单
- SEVIS缴费收据（学生签）
- 简历/CV（部分情况）

### 英国
- 在线签证申请表
- 肺结核检测报告（指定机构）
- CAS号码（学生签）
- ATAS证书（部分敏感专业）

### 申根国家
- 旅行保险（保额≥3万欧元，覆盖全部行程）
- 申根签证申请表
- 指纹采集（首次申请需本人到场）

### 澳大利亚
- 在线申请（ImmiAccount）
- 10年内生物信息采集
- 健康体检（部分情况需指定医院体检）

### 加拿大
- 生物信息采集（指纹+照片）
- 体检报告（指定医院）
- 资金证明要求较高（建议存款≥10万）

## 材料注意事项
1. 所有材料需为英文或目的地国官方语言，或附认证翻译件
2. 银行流水需体现稳定收入，避免大额突然存入
3. 照片需符合目的地国规格要求
4. 护照需有至少2页空白签证页
5. 未成年人需额外提供出生证明公证、父母同意书
